# City Driver Match

Faça a implementação do MVP 1 da plataforma INTEGRETY DRIVER conforme a especificação anexada, incluindo Supabase (Lovable Cloud), autenticação, RLS, cadastro e marketplace funcional. Não crie telas ilustrativas ou dados estáticos: implemente a estrutura relacional completa no banco de dados, autenticação com segregação de perfis (passageiro, motorista e admin), aprovação de motoristas, cadastro de veículos, marketplace de motoristas por cidade com busca e filtros reais, sistema de favoritos, controle de disponibilidade e o fluxo completo de solicitação direta de motorista específico com aceite e recusa.

This project was built with [Lovable](https://lovable.dev).
